Save Manager Help

Problem solving

Ingame save issues

If you have problems with save files showing as empty in the game then you must start a new game in that specific slot from within lcu (make sure you don't overwright important saves. Otherwise you need to load a backup. See 'import backup'). Note: It is normal that the save file slots get shown as 'corrupted' if they don't have any content. You can safely overwright them.

Steam cloud save issue

The save manager won't work if steam cloud is enabled. The online backup will always overwright your loaded save files. Make totally sure that it is disabled in steam.

Main UI explenation

List of profiles

On the left there is the list of available profiles. The slected profile will turn blue as a indication that you selected a current profile.

Create/Delete Profiles

These functions are pretty straight forward. Create makes a new empty profile. Delete profile deletes the profile folder of the currently selected profile in the list left.

Save Manager Details

This section is also pretty straight forward. It shows the profile that is loaded in the game at this moment, it shows which profile from the list is selected right now, under these are the numbers of save file slots found in the game and in the selected profile.

Export functionality

Export profile to folder

The first function exports the current selected profile to a selected folder. Just select the folder on your pc and the profile is fully copied to that location. Note: When you want to export the files loaded in the game it is better to use this feature, see: 'dump game saves to profile' or load a different profile to the game because the profile will still have the old save files from the last load until a new profile gets loaded.

Export slot from game

This second function lets you choose a save file slot loaded in the game to the profile currently selected. Note: This feature will overwright slots in the current profile if the chosen slot number already exists.

Dump game saves to new profile

This third function lets you create a new profile with a new name and makes a dump of all the save files currently used by the game. Note: It's not possible to overwright a existing save profile. Think of a new name.

Import Functionality

Import profile folder

This first import function asks the user for a profile from your pc and imports it to the save manager system.

Import slot to current profile

This second import function looks a lot like the 'export slot from game' only this one uses a slot from your pc instead of a slot loaded in the game. So it asks for a external slot and copies it to the currently selected profile. Note: This function also overwrights the slot in the current profile if you chose a slot that is already in there.

Import backup

When you load a new profile in a new backup is made (max 2 backups are available at any time. The oldest get deleted if you go over the limit). These backups can be restored with this function. It asks the user to choose a backup and loads it to the profile this backup is about. Note: These backups overwright the save files that are already in the profile. If you don't want to lose those you can export them as a profile and then import them afterwards with a rename.

Profile Loading

Load profile to game

This feature is the core of the manager. It uses a few steps to load profiles in a safe way. Firstly it exports the game save files as a backup of the active profile. Then it deletes the files from the active profile. After that it copies the game save files to the active profile and it ends with deleting the game save files to fill it with the save files from the current profile. Note: It's (as you may have seen) forbidden to change save files while the game is running because of some gamebreaking bugs.

Profile paths

The profiles are saved at KF-Files in your game folder.
