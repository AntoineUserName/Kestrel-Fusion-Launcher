Need help to create your character? Press "Create Mod" and read the Characters.md file

Tips: Use an id with 5 letters, try something unique which represents your mod

The textures must be in the DDS format, many softwares can make and edit DDS images

Use the same textures sizes as the textures in this

Put a cheatcode for that you can unlock your character

If you want to add a hat or hairs:

Put the name of the hat/hairs without "HAT_" or "HAIR_" at the start and without the extension

You can't use a hat and hairs in the same character, just one of them or none
